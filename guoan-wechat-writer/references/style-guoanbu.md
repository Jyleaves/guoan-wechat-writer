# "国家安全部"公众号风格指南（操作版）

> 依据：语料库 488 篇精读分析报告（<你的工作目录>\style-analysis\guoanbu-style.md）。本指南只覆盖**原创内容**（约59%，作者"安平/小安/本官微评论员"）；转载通稿（约38%）与活动帖（约3%）不作为模仿对象。

## 适用场景
主题为国家安全、反间谍、数据安全、保密警示、国安工作特稿、涉台涉港斗争表态、政治安全时评时，使用本风格。篇幅：警示科普 800–1500 字；特稿 1500–2500 字；时政评论 1200–2000 字。

## 一、标题（必带标点或修辞，禁止平铺直叙）
- 疑问设问式："XX"们为何……？/ 三年，我们一起改变了什么？/ 闲置硬盘如何"功成身退"
- 感叹警示式：拉警报！群组不是安全屋 / 数据托管切莫"托而不管"！/ 潜伏敌营十载，胜利了！
- 谐音双关式："手"？"守"！/ 碎碎未必真平安 / 别让隔空投送变成隔空投险
- 陈述评论式（时政评论专用，"事件+判断"）：三大论坛同期举行，传递出一个清晰的信号 / 走出一条睦邻友好、合作共赢的光明大道
- 诗意对仗式（特稿）：在北疆，读懂"神秘工作"的分量 / 磨剑铸盾守护政治安全
- 长度 8–20 字为主

## 二、开头（首段=引子+末句点题，禁止开门见山讲概念）
七种套路任选其一：
1. 设问代入（科普警示）："你是否……？……但若失去必要边界，这些看似私密的'小包间'，可能成为威胁国家安全的泄密温床。"
2. 影视/热点切入（评论特稿）：由热播剧台词、新闻热点引出
3. 地点/写景定位（特稿）："XX地处祖国……，边境线XX余公里……"
4. 新闻事件切入（警示）："近日，中国驻X大使馆发布安全提醒……"
5. 背景铺垫+转折（科普）："在……浪潮中，……。但在高效运作背后，也潜藏着威胁国家安全的风险，需要引起重视。"
6. 认知纠偏（先破后立）："很多人以为……，实则不然。……"
7. 故事化叙述（案例）：直接开讲人物遭遇
末句点题模板："……可能成为威胁国家安全的（泄密温床/隐形炸弹）""……再次敲响了警钟""……需要引起重视"。

## 三、主体结构
### 小标题（本账号最鲜明标识，一组必须严格对仗）
- 四字×2：政权腐朽 专制独裁 / 历史大潮 命运抉择
- 四字+四字+三字：民族共荣，扎根基层志不移
- "以……"引领（时政评论）：以合作共赢夯实共同发展根基
- 动宾+定中雅化：铺展亲诚惠容的壮美画卷
- 比喻/双关/网络词（科普）：看不见的"扫描仪" / 翻新硬盘"翻车"
- 固定栏目名："国家安全机关提示"
### 段内列举：破折号条列法（本账号高频结构符号）
`——动宾短语。具体内容。` 逐条展开，例：
——跨界建群，敏感信息"穿马甲"。 ——境外渗透，专业圈层藏暗桩。
### 段落节奏
单段 120–300 字；每小标题下 1–3 段；地域综述用"在XX，……"句首排比。

## 四、结尾（八式选一）
1. 抒情升华（特稿）："草原上的风依旧凛冽……新时代的青年国安干警，正在……书写……的青春答卷。"（有化名时后加一行"（文中人物均为化名）"）
2. 对仗短句+行动号召："群组有界，安全无价；圈层虽小，关乎大局。"
3. 举报渠道固定句（警示/案例标配，逐字复用）：
   "广大人民群众若发现……问题线索，可通过12339国家安全机关举报受理电话、网络举报受理平台（www.12339.gov.cn）、国家安全部微信公众号举报受理渠道或者直接向当地国家安全机关进行举报。"
4. 呼应标题式："……每一块闲置硬盘都能安全地'功成身退'。"
5. 警告表态式（对敌）："……终究逃不过国家安全机关的'火眼金睛'，必将受到历史的审判、人民的唾弃、法律的严惩。"
6. 展望+使命式（时政评论）："'为者常成，行者常至'。……朝着构建人类命运共同体的美好未来坚定前行。"
7. 首尾呼应+致谢读者式（纪念帖，直呼"你"）
8. 精神总结+自我期许式："国家富强、民族复兴、人民幸福，就是党和国家、历史和人民对自己最大的肯定。"

## 五、词汇弹药库（写作时按需取用，忌整段照搬）
- 官方话语：总体国家安全观、隐蔽战线、铸牢中华民族共同体意识、高质量发展、政治安全/数据安全/生态安全
- 四字短语：枕戈待旦、舍生取义、深恶痛绝、振聋发聩、沆瀣一气、铜墙铁壁、钢铁屏障、正本清源、激浊扬清、亮剑发声、起底曝光、相得益彰、入脑入心、落地生根、行稳致远、唇齿相依、同频共振、双向奔赴、万家灯火、岁月静好、刀光剑影
- 对仗：前方吃紧、后方紧吃 / 涉密不上网，上网不涉密 / 一荣俱荣、一损俱损 / 内联八省、外接俄蒙 / 睦邻、安邻、富邻 / 亲诚惠容、命运与共 / 高高兴兴去、平平安安回 / 实干苦干巧干、创新创造创优
- 排比（每项必有实料）：要和平、要安定、要发展、要过好日子 / 为维护世界和平稳定贡献"XX力量"、为推动全球开放合作展现"XX担当"……
- 引号四用法（风格灵魂）：①反讽敌话术（"讲课费""转型正义""文化台独"）②圈点网络词（"大哥""穿马甲""翻车"）③比喻造词（"隐形炸弹""云上仓库""火眼金睛"）④规范提法（"上海精神""一带一路""十五五"）
- 国安特色：国安干警/专案组/收网、境外间谍情报机关/策反/渗透、涉密/失泄密/涉密载体、12339、反颠覆保卫战、许党许国/敢斗善斗/无名无我、国安蓝/藏蓝、"神秘、神奇、神圣"三神战线

## 六、句式节奏
- 四字短语连缀：实干苦干巧干、创新创造创优
- 长短交替：长句交代事实，短句定调（"让'国安蓝'成为草原上最安心的色彩。"）
- 口号式短句独立成句：拉警报！/ 胜利了！/ 统一不是一种选择，而是一种必然。
- 分号对举：一纸绝密电报，承载民族存亡之重；一句"若一去不回，便一去不回"，尽显隐蔽战线先烈的决绝担当。
- 辩证句："变的是技术与环境，不变的是那双向危险伸出的'手'。"
- 祈使句直呼读者（"小安"人格）："在此，小安提醒出国旅行的朋友们注意……"

## 七、事实呈现规则
- 数字：精确+概数修饰并用（4200余公里、约8300平方公里、近300亿份、超过11万列）
- 案例三段式：单位背景 → 违规/风险行为 → 后果（追责/严惩/敲响警钟）
- 引语：先交代场景再引原话，短句、口语化、有情绪
- 化名与保密惯例（硬规则）：
  - 地域单位模糊化：某市/某单位/某行业论坛
  - 干警"小+姓"：小陈、小张；或寓意化名：赵克敌、李守诚
  - 涉案人员"姓+某某"：孟某某；外籍保留外文名：玛丽
  - 涉密细节用统称：标密文件、敏感信息
  - 有化名文末加注"（文中人物均为化名）"
- 写作红线：不出现真实干警姓名、不泄露侦查手段、不描述涉密文件内容、涉案数字可"约/近/余"虚化、涉台表述用"台湾地区/民进党当局"等规范用语

## 八、立场与情感分寸
- 对党：庄重绝对（"许党许国、图新图强、敢斗善斗、无名无我""在以习近平同志为核心的党中央坚强领导下"）
- 对敌：坚决蔑视，以"历史/人民/法律"三重审判收束
- 对人民：邻家式提醒、服务口吻（"小安"人格、12339 举报渠道）
- 禁忌：不调侃政治人物、不娱乐化敌人；网络词每篇仅 2–4 个且限科普场景；抒情集中首尾，正文克制

## 十、格式清单（产出直接用）
1. `# 标题`（保留全部标点）
2. 元信息行：`YYYY年MM月DD日 HH:MM | 作者: 安平 | 来源: 国家安全部`（署名：安平=评论特稿警示案例；小安=短帖科普；本官微评论员=时政评论）
3. 空一行 + `---` + 空一行
4. 正文：段间空一行；`## ` 小标题；列举用`——短语。内容。`
5. 结尾按第四部分八式
6. 发布时间习惯：原创 06:00/07:00/12:00 左右
7. 删除爬虫痕迹：`*原文文件*` 行、`[图片]` 占位等
