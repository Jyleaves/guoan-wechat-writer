# 事实核查协议（硬约束，写作全流程必须执行）

目标：最终文章中的**每一句事实性陈述都必须真实且可查证**。这是比文风更高的优先级——风格不到位可以改，事实出错不可接受。

## 一、事实性陈述的定义

以下内容属于"事实性陈述"，必须可查证：

1. 人物：姓名、职务、任职时间、所属机构
2. 机构：名称、性质、层级关系、成立时间
3. 事件：发生时间、地点、过程、参与方、结果
4. 数据：数字、金额、百分比、增长率、排名、产量、里程
5. 引语：任何带引号的话，必须逐字（或忠实译文）来自信源
6. 法律政策：法律名称、条文内容、政策表述
7. 地理：地名、边界、距离、面积

以下内容不属于事实性陈述（不需要信源，但不得冒充事实）：

- 观点、评价、立场表态（如"美式霸权不得人心"）
- 修辞性表达、比喻、展望性判断（如"相信未来会更好"）
- 我方立场性呼吁（如"我们奉劝……"）

**注意**：立场句可以无信源，但立场句内嵌的事实（如"美国退出《巴黎协定》"）必须查证。

## 二、采集阶段要求

1. 信源分层：
   - **第一层（优先）**：新华社、人民日报、央视新闻、中国政府网、外交部/商务部等部委官网、地方政府官网
   - **第二层**：各国政府/议会/央行官网、国际组织官网（UN/IMF/WB等）
   - **第三层**：路透社、美联社、法新社、彭博社等国际通讯社
   - **第四层**：主流媒体深度报道（金融时报、纽约时报、日经、朝日等）
   - **禁用**：自媒体、论坛、维基百科（仅可作线索，不可作依据）、无法核实出处的转发

2. 交叉印证：每个关键事实至少 2 个独立信源；无法双重印证的，只能以"据报道"（限定第一/二/三层单一信源）形式使用，且全文此类表述不超过 3 处。

3. 时效与日期：
   - 优先 48 小时内新闻
   - 记录每个事实对应的"发布日期+发布机构"，写进事实表
   - 注意跨时区事件（如"当地时间8月3日"与北京时间差异）

4. 事件必须"已发生"；未来日程类内容仅在速览体中使用，且须注明日程来源。

## 三、事实表（写作前必须建立）

格式（Markdown 表格，随文章一起交付）：

| # | 文章中的事实表述（成稿后回填，逐句） | 信源1（机构+标题+URL） | 信源2（如无则空） | 状态 |
|---|-----------------------------------|----------------------|------------------|------|
| 1 | …… | 新华社《……》URL | 路透社 URL | 已核 |
| 2 | …… | 商务部官网 URL | | 单一信源 |

**URL 真实性硬规则**：事实表与谋题附送的 URL 只能**逐字复制自检索工具返回的结果、或实际访问验证过的页面地址栏**；严禁凭记忆/猜测/拼接域名构造 URL（链接造假=整篇作废）。落盘前逐条访问核验：可访问、内容与事实一致、日期匹配，三项不满足即替换或删除该行。

## 四、写作中的硬规则

1. **不虚构**：人名、地名、机构名、数字、日期、引语一律来自信源，不得编造、不得"合理想象"。
2. **不嫁接**：不得把 A 事件的说法安到 B 事件上；不得把旧新闻写成新新闻（除非明确是背景回顾）。
3. **引语零改动**：直接引语必须逐字来自信源（中文原文照抄；外文引语须忠实翻译且标注"据……报道"）；没有原文的"引语"一律改为转述或不写。
4. **数字零漂移**：数字保留信源口径（如"增长0.7%"就写0.7%，不得四舍五入成"近1%"）；信源有出入时取第一层信源并可在事实表注明差异。
5. **疑似即删**：任何一句事实找不到信源，就删掉该句或改写为立场句——宁缺毋滥。
6. **时效标注**：涉及"近期""日前""近日"时，尽量给具体日期；确无日期的保留模糊词但事实表须注明信源发布日期。

## 五、成稿后的逐句复核

1. 把成稿拆成句子，逐句标注"事实句/观点句"。
2. 每个事实句必须在事实表中找到对应行；找不到的：补证（重新检索）或删除。
3. 复核数字、日期、人名、机构名逐字比对信源。
4. 复核引语与信源原文一致。
5. 事实表"状态"列全部为"已核"方可交付。

## 六、对"九万里/国家安全部"风格的特殊处理

这两个账号的文章本身也引用事实，其惯用手法（可模仿其形式，但内容必须真实）：

- "据《金融时报》报道""德意志银行分析认为"——命名信源式，照用，但信源必须真实存在且确实报道过
- "当地时间X月X日""X月X日，……"——具体日期式，日期必须与信源一致
- "另见本号文章《……》"——互引式，工作流生成的互引只能指向真实存在的我方历史产出，无产出则省略此句
- "文末 12339 举报渠道"——国安部体固定结尾要素，照用（该电话/网址为公开真实信息，仍需在事实表登记一次）
