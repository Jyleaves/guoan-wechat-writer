# 研究性文章风格指南（研究体·内参笔法）

> 依据：3 篇获特别好评的成品样本（《集装箱反垄断研究》《全球战略石油储备研究》《算力金属博弈研究》，本机样本原档 D:\WordPDFPPT\新建文件夹\ 中的 1集装箱.docx、1石油.docx、1算力金属.docx，**可选，不随技能分发**）+ 8 篇同类样本（无稀土磁铁/智能汽车/机器人/租赁算力/数据安全/赤潮/人工智能拟人化互动等）+ 用户保存的写作与核验提示词（1提示词.docx，仅作参考，权重低于好评样本）。文本提取副本（本机可选）：<你的工作目录>\style-analysis\research-samples\。
> 版本说明：本指南为研究体（研究性文章）专属规范。**研究体是独立研究报告文体，不是微信公众号文章**：语言基因与九万里/国安部同源（借用公众号文风的句法词汇），但体裁模板层完全独立——交付物为与示例同格式的 Word 文档（.docx，公文排版）+ 事实核查表；无公众号元信息行、无署名、无推送模板、**不配图**（对比见第八节）。

## 一、文类定位与触发

**定位**：独立于公众号的"智库型研究文章"（内参/公文体）。选题集中于产业、资源、科技、供应链、能源、法律规制等大国博弈专业领域；笔法为"内参体"——平实、严谨、客观、事实密度极高；立场为我方视角（研判对华风险与影响、提出对策建议）。**交付物：与示例同格式的 Word 文档（.docx，公文排版）+ 事实核查表（Markdown 单独交付）。不是微信公众号文章——不写元信息行、不署名、不套推送版式、不配图。**典型句式见 3 篇好评样本。

**触发词**（用户此类请求必先说明主题）：
- 主触发（显式体裁词）：研究性文章 / 研究报告 / 分析报告 / 深度分析报告 / 内参（体、风格、笔法）/ 研究体 / 研判报告 / 专题研究 / 产业研究
- 请求形态："写一篇关于XX的研究性文章""针对XX写一份分析报告""围绕XX公告/报告写一篇分析"
- 次触发（组合特征，即使未说体裁名）：主题 + 要求"深度分析/详细分析" + "引用权威来源与数据" + "分析对中国的风险/影响" + "提出对策建议"
- 防误触发：普通时评请求（"写一篇公众号文章"）不触发研究体；研究体≠谋题；用户给的是新闻报道事件而要求时评风格时走九万里/国安部判定。

## 二、篇幅与结构骨架

**篇幅**：4000–8000 字（好评样本实测：集装箱约 4000、算力金属约 4500、石油约 8300；目标带 4000–6000，数据丰富的多部分结构可至 8000）。**全文无文章大标题、无元信息行、无署名、无图——正文从总论定调段直接开始（3 篇好评样本实证）。**

**默认三段式骨架（两篇重点好评样本实证；用户提出其他具体要求时，以用户要求为准调整）**：
1. **总体情况**：总论定调段 → 分层实证（一、二、三……每节一个维度/主体：现状、重要性、对手动作等）
2. **对华风险研判**：上述情况/动作对我国的直接与潜在风险、影响、短板暴露
3. **对策建议**：2–5 条，每条=段首判断句+具体法律/政策/机制抓手

**重点参照结构（好评样本实证，任选或组合）**：
- **算力金属式（与默认三段式同构，重点参照）**：总论定调段 → 一、重要性 → 二、对手举措 → 三、对策建议
- **集装箱式（重点参照）**：总论定调段 → 分层实证（一、二、三、四……每节一个维度/行业/主体，如"美资药企哄抬药价""航运巨头串谋运力""化肥粮食巨头操纵价格"）→ 在华实体与联系人（可选，风险研判抓手）→ 五、对策（独立节，（一）（二）（三））
- **石油式（多部分纵深变体）**：第一部分/第二部分/第三部分……每部分=该部分总论段+分主体实证段（每主体一段）+"重点总结与建议"（编号条列，每条一两句短促有力）；同一主体可在不同部分以不同角度重复出现（如美、荷、德、日四国贯穿机制/效应/转型三部分）
- **无稀土磁铁式（变体）**：总论段 → 分层实证（政府层面/企业层面……）→ 涉我影响与对策收束

**共性骨架（任何结构强制满足）**：
1. **总论定调段**（无小标题，250–400 字）：点题+定性判断+预告结构。定调句常用"并非……而是……"辩证式（集装箱："……并非单纯的司法反垄断行动，而是具有深层政治意图的供应链遏制举措"）；末句常为"客观评估……，对……具有重要参考价值"或"本报告基于……，系统复盘……、研判……并提出对策建议"。
2. **分层实证**（2–5 节）：每节 2–5 个自然段，每段一个主体/维度；节标题"一、XX"。
3. **涉我风险研判**：必须有"对华/对我"的风险、影响或优劣势分析（研究体的涉我锚点，同谋题锚点精神）。
4. **对策建议收束**（2–5 条）：每条=段首判断句+具体法律/政策/机制抓手（法律名称、机构、平台、比例、期限、品种），禁止空喊。
5. **可选总结**：文末 1–3 个"重点总结"短段（每段一两句）或每部分末尾编号总结（石油式）。

## 三、段落微观结构（强制"三件套"）

每段 = 定调句 + 证据链 + 机制句：
1. **段首定调句**（20–40 字判断句，直接给出该段论点或该主体状态）："美国作为全球最大应急库存持有国目前正深陷前期过度抛储带来的补库困境。"禁止"随着……的发展""在……背景下"起笔（背景式起笔全文仅总论段允许一次）。
2. **证据链**："据X媒体/机构 X年X月X日 报道/发布/披露/通报/受理，……" + 精确到日的日期 + 数字（金额、百分比、数量、时长）+ 案例名/法律名/公告名/案号。信源须具名（可写"据彭博社2026年3月4日报道"），机构首次出现可中英对照。
3. **机制/影响解释句**（1–2 句）：为什么重要、传导逻辑——"这意味着/此举实质上/这种……机制/这一转变意味着"。
- 段落长度 200–400 字；一段只讲一个主体或一个维度。
- 段落内不用无序列表；编号条列仅用于"重点总结/对策建议"收束处（好评样本实证）。

## 四、标题与小标题规范

- **小标题一律不含标点符号**（好评样本 100% 遵守，用户提示词亦强调）："美资药企及分销商在危机期间哄抬价格与控制供给""北美与亚太核心大国储备调控现状""完善以技术与纯度为导向的精细化出口管制机制"。
- 小标题为判断式短语，12–20 字；一级用"一、XX"，二级用"（一）XX"。
- **文章大标题**：直陈式名词短语或主副式判断（可带冒号），12–24 字；不套用九万里反问/感叹/省略号套路（样本标题如"欧盟UN R171落地对中国智能汽车产业的影响""境外租赁算力"）。
- 关键数字/定调短语可加粗（延续九万里"金句加粗"传统，研究体加粗对象以数字与机制关键词为主）。

## 五、语言规范

**保留共通基因**（详见 SKILL.md"两账号共通风格基因"，研究体取舍如下）：
- 保留：四字短语与对仗；"不是……而是……""从……转向……"辩证句；长句装完整事实链+短句定调；观点句后必跟证据；每段至少一处"但/然而/实质上/不过"转折；具体日期+数字嵌入。
- 特化（研究体与九万里体/国安部体的差异——去修辞、归零情绪）：
  1. **去文学修辞**：不用"像一颗投入政坛的重磅石子"式比喻；反问句克制（每篇≤2处）；引号仅用于文件/项目/政策/计划专名（"Vault项目""TRACE-Ga"）与极少量圈点词，不用反讽引号；不用省略号悬念结尾。
  2. **情绪归零**：对对手不嘲讽不喊话，用事实与机制说话（"美方试图将通胀危机转嫁给我国实体"，而非"美方阴谋败露"）。
  3. **事实密度**：事实句占全文 ≥60%；平均每 100 字至少一个数字/日期/机构名。
  4. **我方姿态**：客观陈述我方优势（规模、技术、主动权）与短板（依赖、暴露、产能），不喊口号、不抒情。
- **词汇弹药库**（好评样本高频，按需取用，禁止整段照搬）：微观传导机制（签名词）、供应链安全、产业链、产能纪律、卡脖子、战略储备、商业储备、出口管制、两用物项、长臂管辖、域外管辖、反垄断、关税壁垒、贸易救济、本土化、友岸外包、去风险、脱钩、围堵、博弈、定价权、话语权、战略自主、产业安全、物理断供、断供风险、库存、囤积、补库、精准滴灌、逢低买入、逆周期、价格锁死、最终用户许可、绿色通道、衍生交易品种、伴生矿、精炼加工、高纯度、量产、产线、博弈重心。

## 六、事实核查强化项（研究体专属，在通用协议之上）

研究体事实句密度是九万里体 3–5 倍（每篇通常 25–45 个"据……报道"句），出错概率同比例放大。除执行 `fact-check-protocol.md` 全部条款外，增加：

1. **五类高发错误逐项过**（源自《1算力金属》样本返修事故——该版本正是因事实错误返修，修正后获特别好评；以下为其疑似错误点，作为错误类型清单）：
   - **机构译名**：外媒/外国机构名按权威中文译法书写，首次出现中英对照（如"美国进出口银行（Export-Import Bank of the United States，EXIM）"；样本中"出口导入银行"即此类错误）；拿不准就查新华社/央视用法。
   - **金额量级**：专项/试点项目的金额出现国家级量级（如"540亿美元投向小众回收项目"）必须双信源复核；美元/人民币/欧元单位逐一核对，不混用。
   - **编号逐字**：总统公告号、法律条款号、合同编号、案号（如"第11001号公告""SP8000-26-D-0002"）无法逐字核实就不写编号，只写名称。
   - **百分比口径**：进口依赖度/市场份额/占比必须带统计口径（谁统计、哪一年、什么口径）；"98%的镓"式孤数必须有对应信源，且要写"精炼加工环节""按哪年数据"等限定。
   - **日期逻辑**：签署日/生效日/报道日/事件日分别标注（"2026年6月1日签署、6月8日生效"）；当地时间与北京时间按原文标注，禁止换算；未来日程用"预计/将于/计划"并注明来源。
2. **8–12 个关键事实自检**（硬流程，源自用户核验提示词"进行验证"部分）：交付前抽取全文最重要的 8–12 个带来源事实，逐一重新检索比对原文，发现出入给出修正表述并回填成稿。
3. **信源层级扩展**：研究体允许使用的信源扩展到——官方报告（USGS/欧盟委员会/部委公告/法院文书）、国际组织（IEA等）、头部财经媒体（彭博/路透/日经/金融时报/华尔街日报/德国商报/劳氏日报等）、律所与智库报告（第四层，须具名且标注发布机构与日期）。小媒体/自媒体/论坛仍禁用。
4. 单一信源事实全文 ≤3 处（与通用协议一致）；事实表 25–45 行，每个"据X报道"句一行。
5. 交付时剔除"核实员说明"类流程元文本（如"作为极其严苛的资深核实员……"）与格式残留（如"**【】"错乱标记），除非用户明确要求保留。

## 七、反AI腔清单（研究体版，替代通用规则）

**禁用**：总而言之/综上所述/值得注意的是（"简而言之"全篇限 1 次，好评样本实证）；"首先/其次/再次"堆砌；空泛排比；"一、背景 二、现状 三、对策"空模板标签（研究体允许"重要性/举措/对策"这类**有实料命名**的分层）；结尾空号召（"让我们携手……"）；"赋能/抓手/闭环/底层逻辑"式网络黑话（政策原文除外）；段首"随着/在……背景下"滥用（全文≤1次）；"大量/众多/显著提升"式虚指。
**保留**（好评样本实证存在）：编号条列总结、"据X报道"具名归因、四字短语、辩证句、转折推进、数字密集长句、段首定调句。

## 九、配图

**研究体不需要配图**（3 篇好评样本均不含图）。交付物只含正文与文字数据——不生成图表、不配封面、不写配图方案。

## 十、提示词参考文件使用纪律（1提示词.docx）

用户保存的网页版 AI 提示词仅作参考，**不直接使用**，权重低于好评样本。其中与好评样本实证一致、可继承的项：素材扎实（"据xxx报道"+报道时间）、自然段+段首重要句、小标题无标点、"内参笔法"（平实严谨客观、微观传导机制复盘、风险分析+应对建议）、重点总结短段、核验法（8–12关键事实+修正建议）。与样本不一致、**不照搬**的项：结尾 300 字总结并非固定要求（结构A/B样本无独立总结段）；"围绕单个链接写"仅是当次任务形态，不是研究体固定入口；"去除所有文学修辞和情绪化表达"仅适用于研究体，不得扩展到九万里/国安部体。

## 十一、Word 交付规范（与示例同格式）

交付物：① 文章 Word 文档（.docx，排版与示例一致）② 事实核查表（Markdown，单独交付，不进 Word 正文）。**不配图。**

格式实测（两篇重点好评样本——集装箱与算力金属——完全一致）：
- 正文：仿宋三号（16pt，sz=32 半磅）、西文 Times New Roman、两端对齐、首行缩进 2 字符（firstLineChars=200）
- 一级标题（"一、XX"）：黑体三号、黑色、不加粗、同样首行缩进 2 字符
- 二级编号（"（一）XX"）：位于段首、随正文仿宋，不设独立标题行；确需独立二级标题行时用楷体三号
- 页面：A4（11906×16838 twip）、页边距上/下 2.54cm、左/右 3.175cm、行网格 lines/312
- 无文章大标题、无元信息行、无署名、无图——正文直接从总论定调段开始
- 备选变体（1石油）：宋体小四正文、标题宋体加粗（大标题 13.5pt、节标题 12pt）

生成工具链（随技能分发，位于 <技能目录>\tools\research-docx\；依赖 pandoc）：
1. 起草正文为 Markdown：`# 一、XX`=一级节标题；`## （一）XX`=独立二级标题（少用）；"（一）……"段内编号直接写进段首；正文自然段。
2. `pwsh <技能目录>\tools\research-docx\md2docx.ps1 -Input 文章.md -Output 文章.docx`（默认公文式；`-Variant songti` 宋体小四式；未安装 pandoc 时脚本会给出安装提示）
3. 校验（硬门槛）：解压 docx 抽查样式表（Normal=仿宋三号+首行缩进2字符、Heading1=黑体三号）与页面 sectPr（A4 及上述页边距）；全文无 Markdown 残留（**、#、[图片]）、无元信息行、无署名。
模板：<技能目录>\tools\research-docx\reference.docx（公文式）、reference-songti.docx（宋体小四式）；重建模板用 make-reference.ps1（纯 .NET，无需 pandoc）。
保存：docx 与 md 底稿存 <你的工作目录>\outputs\YYYY-MM-DD-标题\。
