# 国安系公众号写作工作流

目标：用户提出"搜集最新时事新闻写公众号文章"或"针对XX搜集新闻写文章"时，产出一篇**风格严格一致、事实逐句可查证**的公众号文章。风格模仿对象：微信公众号"九万里"（国际时评）与"国家安全部"（国安评论），规范提炼自用户整理的约 1500 篇语料（<语料库目录（可选）>\）。

## 硬性优先级（任何步骤冲突时以此为准）
1. **事实真实可查证**（最高）：事实核查协议全文见 `references/fact-check-protocol.md`，必须逐条执行。
2. **风格完全一致**：对应风格指南见 `references/style-jiuwanli.md`、`references/style-guoanbu.md`，用词句式对标指南，但**不得抄袭**——化用句式与词汇弹药，不搬运语料原文段落。
3. 反 AI 腔：**只以两本风格指南第九章的"反 AI 腔清单"为准，禁止套用 remove-ai-style 等通用反 AI 规则**。语料风格签名（必须保留，通用反 AI 规则常误杀这些写法）：
   - 引号+关键词：标题与正文大量使用（九万里 32% 标题带引号），是风格灵魂
   - 比喻造词："关税大棒""隐形炸弹""火眼金睛""抱薪救火"等
   - "不是……而是……""变的是……不变的是……"辩证句
   - 反问句标题/小标题（九万里约 30% 标题带"？"）
   - "——"条列法与速览体编号条目（格式签名）
   - 排比句（但每项必须有实料）
   真正要防的 AI 腔（语料中确实不存在的）："总而言之/综上所述/值得注意的是/在……的今天"式起笔；空泛排比；"大量/众多/显著提升"式虚指；"一、背景二、现状三、对策"式模板化小标题；"让我们携手共进/共创美好未来"式结尾空号召；"首先/其次/再次"粘连词堆砌。

## 两账号共通风格基因（任何风格下都必须保持）
"九万里"与"国家安全部"同源（九万里即国安部所办账号），语言底色一致。**风格切换只换"体裁模板层"（篇幅/标题套路/栏目格式/署名/词汇领域），不换语言基因**。以下八条在任何风格下强制保留：
1. 引号四用法（反讽敌话术、圈点网络词、比喻造词、规范提法）——两账号共用的风格灵魂
2. 四字短语+对仗+排比节奏；排比每项必有实料
3. 长句装完整事实链+短句定调；每段至少一处"但/却/然而"转折
4. 观点句后必跟证据（数字/引语/来源）；数字零漂移
5. 开头"具体由头+末句点题"，禁止开门见山讲概念
6. 文言/成语化用每次一处不堆砌；口语词穿插克制
7. 反 AI 腔清单（两本指南第九章）：禁用"总而言之/综上所述/在……的今天"式起笔、空泛排比、虚指数量词、模板化小标题、结尾空号召
8. 立场分寸：对华以事实支撑、对第三方讲利益不讲道德审判、批判必须有具体抓手

切换时的替换项（体裁模板层差异）：九万里体=2000–2800字/国际时政术语（博弈、霸权、战略自主、关税大棒）/总-分-总四段式、6–12个小标题/省略号悬念结尾/署名"九万里快评/万里无云/万里晴"；国安部体=800–2000字/国安话语（隐蔽战线、国安干警、境外间谍情报机关、许党许国）/严格对仗小标题+"——"条列法/12339举报渠道固定句或抒情升华结尾/署名"安平/小安/本官微评论员"。

## 工作流程

### 第一步：解析需求、判定风格与体裁
1. 提取用户意图：主题/事件是什么；是否需要搜集最新新闻；用户是否显式指定风格。
2. 风格判定（优先级从上到下）：
   - **用户显式指定优先**：用户说"用九万里（九万里体/万里）风格"→九万里体；"用国家安全部（国安部/安平/小安/本官微评论员）风格"→国安部体，可再按子型细分（安平=评论特稿警示案例；小安=短帖科普提醒；本官微评论员=时政评论）；"速览/周报/本周要闻"→万里追风速览体；"论剑/专家访谈/问答"→万里论剑体。
   - 用户未指定时按主题自动判定：
     - 国际时事/外交/大国关系/国际安全 → 九万里体（2000–2800 字）
     - 国家安全/反间谍/数据安全/保密警示/国安特稿/涉台涉港表态 → 国安部体（800–2000 字，按子型定）
     - "本周要闻/新闻速览" → 万里追风速览体
     - 无法判定时默认九万里体，交付时说明理由。
   - 用户指定风格与主题自然体裁不符时：以用户指定为准，但开头用一句话说明按主题本可推荐另一种风格，用户可再改。
3. 无论选哪种风格，共通风格基因不变（见上节）。
4. 向用户声明本次采用的风格、体裁、篇幅目标、署名模板。**用户中途要求切换风格时：复用已建事实表与信源（无需重新检索），只重做起草与复核步骤。**

### 第二步：搜集最新新闻（真实性与权威性第一）
1. 用 web_search 多轮检索，关键词覆盖：事件主体+机构名+近 1-3 天时间窗。
2. 信源分层（详见事实核查协议第二部分）：
   - 第一层：新华社、人民日报、央视、中国政府网、部委官网
   - 第二层：各国政府/国际组织官网
   - 第三层：路透/美联/法新/彭博
   - 第四层：主流媒体深度报道
   - 禁用：自媒体、论坛、维基百科（仅可作线索）
3. 每个关键事实找 ≥2 个独立信源交叉印证；单一信源事实须以"据报道"（限定第一/二/三层）形式使用且全文 ≤3 处。
4. 只采"已发生"事实；未来日程仅用于速览体并注明来源。
5. 记录每个事实的"机构+标题+URL"，建事实表（见协议第三部分）。

### 第三步：起草前准备
1. 加载对应风格指南（read 工具读 `references/style-jiuwanli.md` 或 `references/style-guoanbu.md`）。
2. 按指南确定：标题类型、开头套路、小标题体系、结尾方式、本主题可用的词汇弹药（从指南词汇库中选取，禁止整段照搬）。
3. 按事实表确定：哪些数字/日期/引语可用，哪些只有单一信源需加"据报道"。

### 第四步：起草
1. 严格按风格指南逐项写：标题 → 元信息行 → 分隔线 → 开头（引子+点题）→ 小标题分段 → 结尾。
2. 事实句只能来自事实表；引语必须逐字（或忠实译文）来自信源。
3. 篇幅按体裁目标控制。
4. 写完自查：对照风格指南的反 AI 清单与格式清单逐项过一遍。

### 第五步：成稿逐句复核（硬门槛，不过关不得交付）
1. 把成稿拆句，标注"事实句/观点句"。
2. 每个事实句在事实表中必须有对应行；缺行→补证或删除。
3. 数字/日期/人名/机构名与信源逐字比对；引语与信源原文比对。
4. 事实表状态列全部"已核"。

### 第六步：交付
1. 交付物：
   - 文章 Markdown（公众号排版可直接粘贴的格式，见下方模板）
   - 事实核查表（claim ↔ 信源 URL）
   - **配图方案清单**（`YYYY-MM-DD-标题-配图方案.md`，见"配图工作流"节）
2. 保存：文章存 `<你的工作目录>\outputs\YYYY-MM-DD-标题.md`，核查表与配图方案存同目录；生成的图片存 `<你的工作目录>\outputs\images\`。
3. 向用户汇报：体裁、选题依据、信源数量、事实核查结果摘要、署名与来源设置说明、配图交付情况（已生成几张/需自找几张）。

## 配图工作流（自动+半自动结合，两条红线）

**红线1**：新闻照片/现场照片/人物照片/机构实景照片必须真实拍摄来源，**严禁 AI 生成**（否则违反事实真实性原则）；AI 生成仅限封面、装饰插画、海报、示意图类。
**红线2**：图表与示意图中的数据只能来自事实核查表已核实项；没有序列数据就不画走势曲线，绝不"美化"出未核实的数据点。

### A. 全自动：数据图表与示意图（直接产出 PNG）
1. 起草完成后，从事实表挑选可图表化的已核实数据（点数据→卡片图/条形图；有序列→折线图）。
2. 用 Python matplotlib 生成中文图表，模板脚本：`<你的工作目录>\tools\make_chart.py`（已配置微软雅黑字体；官方媒体风格：深蓝 #1f3864 + 暗红 #b02a2a；图底必标"数据来源"）。
3. 风险传导、逻辑关系类内容生成"示意图"（方框+箭头），图内文字全部来自事实表，并标注"示意图……不代表官方结论"。
4. 输出至 `<你的工作目录>\outputs\images\`，在文章对应位置保留 `[图片]` 占位+图注，在配图方案清单中挂接文件路径。
5. 生成后用 PIL 程序化校验（字体加载成功、非空白）；模型不支持图像输入时以程序校验代替目检。

### B. 半自动：配图方案清单（用户照单找图，工作量最小化）
每篇交付一份配图方案清单，每个配图槽位写明：位置锚点、图型分类（新闻照片/资料图/图表/示意图/封面）、画面内容描述、**图库检索式**（可直接复制到图库搜索框）、推荐图库、图注文案（已写好）、版权提示。
图库白名单：新华图片库、人民视觉、视觉中国、央视网图库；国际免版权：Pexels/Pixabay/Unsplash；历史资料图可用 Wikimedia Commons（保留署名）。

### C. AI 生成提示词（仅限允许类别）
封面、装饰插画、海报类在清单中给出可直接粘贴的中文提示词（含风格与配色约束：深蓝暗红系、扁平商务风格、"无任何文字"——避免 AI 生成文字乱码）。新闻现场照片、人物照片、机构实景照片严禁 AI 生成。

### D. 可选升级：自动找图（需用户授权安装）
若用户安装 Tavily CLI 并登录：`tvly search "关键词" --include-images --json -o result.json` 获取图源 URL，再用 PowerShell `Invoke-WebRequest` 下载；仅限免版权图库来源，商业图库仍需人工授权。

## 谋题工作流（选题报送与审核，智能触发）

### 触发与报送类型判定
1. 用户请求含"谋题/报题/报送选题/明天选题/次日选题/下周选题/本周选题/时评精选选题/万里论剑选题/选题审核"等 → 启动本流程。
2. 类型判定：
   - 工作日（周一至周五）请求"谋题"→ 报送**次日**谋题 2-3 条（部门习惯：17:30 前报送，收到请求立即执行）
   - 周日（或"下周选题"）→ 报送**下周**时事热点重大选题 2-3 条
   - 用户点名"时评精选/万里论剑"→ 在报送中为该栏目推荐成熟选题（万里论剑=专家访谈体，选题须适合问答式深度解读）
3. 用当前日期判断星期与报送类型，并在谋题文件头部注明。

### 选题来源（硬约束）
- **优先谋题来源（国际传播头部媒体）**：环球网/环球时报（huanqiu.com、globaltimes.cn）、中新社/中国新闻网（chinanews.com）、新华社、人民日报、央视新闻、中国日报、参考消息
- **权威外媒**：路透社、美联社、法新社、彭博社、共同社、韩联社、越通社、日经新闻、金融时报、纽约时报、华尔街日报、华盛顿邮报、卫报、BBC
- **官方发布**：各国政府/部委/军方/机构官网声明
- **禁用**：小媒体、自媒体、营销号、论坛（视野窄、不准、不全）；某事件唯一信源为小媒体的，不报送

### 过审锚点模式（为什么有些谋题能过审——从已发表文章倒推的规律）
金标准：语料库中九万里文章**全部是过审发表物**，谋题须模仿它们的选题锚点与写法。已实证的"谋题→发表文章"对应（补充至2026-08-13的语料确认）：
- 谋题"美日时隔28年联合'救汇'"→ 发表《时隔28年，美日再度联手救市！》（2026-08-05）：标题核心锚点（时隔28年/救市）几乎直用，只加润色与感叹号
- 谋题"新版防卫白皮书露锋芒：日本扩军备武的脚步，早已踩过了红线"→ 发表《高市首份防卫白皮书四大危险信号》（2026-08-06）：判断式标题+"四大危险信号"条列结构
- 谋题"苏林访澳新，越南南向外交再落重子"→ 发表《苏林出访澳新，竹式外交再添新枝》（2026-08-11）：主副式结构直用，副题换成账号既有话语谱系词（"竹式外交"，此前发表过《竹式外交再加码，苏林连访南亚两国》）
- 谋题"借长崎纪念炒作'国格'，民进党谋独闹剧法理难容"→ 发表《"有损国格"？民进党当局自取其辱！》（2026-08-13）：锚点词"国格"保留，法理依据（开罗宣言/波茨坦公告/2758号决议）即文章结构
- 谋题"汉光42号实兵演习"→ 发表《民进党大搞军演，目标直指解放军》（2026-08-07，同主题锚点）
结论与四条锚点（硬规则）：
1. **涉我性是第一锚点**：选题必须能锚定中国——直接涉我事件（台海/南海/中美/中企）、中国成就、中国周边、对华潜在影响（含揭批美西方对华动作）。纯外国话题原则上不报；纯宣传味、无博弈对手的素材（如展会预告）过审率低。中国成就类轻话题可过审（语料《中式英语走红全球社交圈》2026-08-10 即例）。
2. **标题即成品**：谋题标题按发表标题标准写——判断式/主副式/设问，锚点词要"可直用"（时隔28年、国格、竹式外交、四大危险信号），12-20字，忌新闻式平铺。
3. **简述=信源句+事实句+态度铺垫句+拟写句**：态度铺垫句点出分量与信号（"这一消息，像一颗投入南美政坛的重磅石子……"）；"拟……"动词链即未来文章的结构骨架（事实=文章开头素材，拟句=文章分段）。
4. **有博弈对手、有具体抓手**：事件含明确博弈双方与具体数字/日期/人物；拟写句落点必含我方立场或影响研判。
注意事项：示例中未见发表的选题≠一定未过审（谋题到发表通常有 1-3 天周期）；判定"过审概率低"只适用于明显缺涉我锚点或纯宣传味选题。

### 谋题格式（每条，严格参照示例写法）
```
选题：判断式标题（主副式"事件：判断"或设问，含我方角度）
简述：据XX媒体X月X日报道/据XX官方X日声明，<事实句2-4句，含具体数字、日期、机构>。<态度铺垫句，点出分量与信号>。拟梳理……剖析……拆解……研判……揭示……（动词链收在我方立场与影响研判）
链接：<官方文章链接>（官方媒体官网版优先；有 mp.weixin.qq.com 公众号推文链接则一并附上并标注"公众号推文"）
```

### 官方文章链接获取方法（微信公众号难爬的解法）
1. 官方媒体公众号推文通常同步发布在官网，优先找官网版：环球网 huanqiu.com、中新网 chinanews.com、新华网 news.cn、人民网 people.com.cn、央视 cctv.com、中国日报 chinadaily.com.cn、光明网 gmw.cn
2. 尝试找 mp.weixin.qq.com 链接：检索"事件关键词 微信公众号"；检索结果中出现 mp.weixin.qq.com 链接则附上并标注"公众号推文"
3. 若装有 Tavily CLI：`tvly extract "<mp.weixin.qq.com链接>"` 提取推文正文（微信部分页面可抓取；失败则改用官网版）
4. 官网版与公众号推文都找不到 → 该选题不报送

### 审核与写作流程（关卡式）
0. **生成谋题前**：先 read `<你的工作目录>\feedback\learned-patterns.md` 全文与 `<你的工作目录>\feedback\feedback-log.md` 最近 20 条，规避已踩过的坑（格式、锚点、信源、审核人偏好）。

4. 同一事件已被本工作流写过文章的（查 outputs 目录），不再重复报送

## 反馈学习协议（持续进化：越用越聪明）

三层记忆全部文件化、跨会话持久（借鉴 self-improving-agent 的语义/情节记忆架构，以工作流纪律替代运行时钩子）：

1. **经历记忆**：`<你的工作目录>\feedback\feedback-log.md`——每次谋题审核结果、每篇文章的用户反馈，按 FB-XXX 编号立即追加（时间/类型/条目摘要/审核意见原文/教训）。**任何审核或反馈发生后必须记录，不得遗漏**。
2. **模式记忆**：`<你的工作目录>\feedback\learned-patterns.md`——从反馈提炼的稳定规则（过审锚点、格式模板、禁忌、偏好），每条附来源与置信度。**谋题生成与起草前必读**（见谋题流程第0步、写作流程第三步）。
3. **技能本体**：本 SKILL.md 与 references/——长期工作指南。

固化策略（防止把单次噪声当规律）：
- 同一信号在反馈日志中出现 **≥3 次**，或用户明确要求 → 才提炼进 learned-patterns.md；写入本 SKILL.md/风格指南前须用户确认，并加进化标记 `<!-- 进化: 日期 | 来源: FB-XXX -->`
- **版本管理**：每次对 SKILL.md/风格指南/协议的实质修改，按语义化版本（semver）更新 `<你的工作目录>\VERSION`、SKILL.md frontmatter 的 `metadata.version`、`<你的工作目录>\CHANGELOG.md`（补丁=修正与微调；次版本=新增功能/新经验模式；主版本=架构性变更），并用 `tools\build-release.ps1` 重新生成分享包
- 用户说"复盘/进化/总结教训/更新风格库"→ 立即执行合并：读全量日志 → 抽象模式 → 更新 learned-patterns.md → 列报拟提升进指南的条目，征得同意后修改
- 语料库更新后说"更新风格库"→ 重新抽样分析语料、更新风格指南与过审锚点实证
- 正面反馈同样记录：被采纳谋题的标题/简述/角度，是未来谋题的正例参照

边界说明：审核若发生在对话之外（如工作群），用户把结果/意见转发给 agent 一次，即被永久记录并在后续会话生效。
